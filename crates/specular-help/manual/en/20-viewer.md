The viewer shows one image at a time. Nothing you do here changes the file.

## Moving through a folder {#navigate}
- [[key:next]] and [[key:prev]]: next and previous image
- [[key:first]] and [[key:last]]: first and last image
- [[key:go-to]]: jump to an image by its number

These commands are unavailable when the folder holds only one image. Open a folder, or an image in a folder with others.

## Zooming and panning {#zoom}
- [[key:zoom-in]] and [[key:zoom-out]]: zoom one step
- Mouse wheel or touchpad pinch: zoom around the pointer
- [[key:zoom-fit]]: fit the whole image
- [[key:zoom-fill]]: fill the window
- [[key:zoom-to:100]]: actual size, one image pixel per screen pixel
- Hold [[key:zoom-rectangle]] and drag: zoom into a rectangle
- Drag the image or use the arrow keys: pan
- [[key:navigator]]: small map of the whole image
- [[key:loupe]]: magnifier at the pointer; hold, or tap to keep it on

To set the zoom a new image opens at, use Settings › Viewing.

## Rotating and flipping {#rotate}
- [[key:rotate-left]] and [[key:rotate-right]]: turn a quarter turn
- [[key:flip-horizontal]] and [[key:flip-vertical]]: mirror

This changes only the view. To save a turned copy, use [Convert](convert).

## Files {#files}
- [[key:copy-image]]: copy the image
- [[key:copy-path]]: copy its path
- [[key:trash]]: move the file to the trash
- [[key:undo]]: put it back

See [Working with files](files).

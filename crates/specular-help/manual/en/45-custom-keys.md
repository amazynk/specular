1. Press [[key:customise-keys]], or choose **Customise keys…** in the palette.
2. Find the command and choose its key.
3. Press the new key.
4. If the key is already used, Specular says by what. You can swap the two.

Each mode, such as cull or medical, has its own keys. A key not set in a mode does what it does in the viewer.

**Reset** goes back to the default keys.

## The toolbar {#toolbar}
Press [[key:customise-toolbar]] to choose which buttons the toolbar shows, and in what order.

The [keys reference](keys) lists every key.

A profile adds the modes, commands, toolbar buttons and Settings pages for one kind of work. General is always on.

Every file opens whatever profiles you choose. Profiles only decide which extra tools are offered.

## The profiles {#list}
- **General**: photos and everyday images. Always on.
- **Engineering**: technical drawings and 3D models. See [drawings](drawing) and [3D models](mesh).
- **Medical**: DICOM studies, measurements, linked series and fusion. See [medical images](medical).
- **Science**: astronomy, microscopy and scientific data. See [scientific images](science).
- **Maps (GIS)**: maps, GPS tracks and elevation models. See [maps](maps).

## Choosing {#choose}
Specular asks on first start. Change it any time in Settings › Profile.

## Tools for this file only {#chip}
If a file needs tools that are off, a chip in the toolbar offers them. Choose it to turn them on for this session; the message that follows lets you keep them on.

A command whose profile is off is greyed out in the palette, with the reason.

Viewing tools work in every profile, such as the [three-plane view](medical-3d#mpr) of any volume.

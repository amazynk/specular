# `unsafe` register

Specular uses `unsafe` only where absolutely necessary (DESIGN.md §1, principle 9). The workspace
denies `unsafe_code`; every exception is the smallest possible item with `#[allow(unsafe_code)]`, a
`// SAFETY:` comment, and a row here. Reviews reject unlisted uses. Decoders of untrusted input aim
for zero.
